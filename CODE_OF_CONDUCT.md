# Code of conduct

Be kind, assume good faith, and keep discussion about the work. Harassment,
discrimination, and personal attacks aren't welcome in any space this project uses.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
To report a problem, contact the maintainer privately through GitHub. Reports are
kept confidential.
